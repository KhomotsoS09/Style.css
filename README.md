MyWebWebsite


Website with different pages created with the use of HTML and CSS on various topics.


Pages:
- index.html - Home page
- about.html - About page
- contact.html - Contact page
- enquiry.html - Enquiry form
- product.html - Product page

About:
Every page represents a topic. Style codes can be found in `style.css`.


How to run:
Open `index.html` file in any web browser.


Overview:
Multi-page website created in HTML and CSS. Contains different topics on individual pages.


Features:
- Different pages with distinct topics
- Consistent styling with the help of CSS file
- Easy navigation between pages
- Forms of contact and inquiry for users


Tech Stack:
- HTML5 - HTML5
- CSS3 - CSS3
- Without use of any framework or library


Project Structure:

- index.html
- contact.html
- enquiry.html
- about.html
- product.html
- style.css
- index

Prerequisites:
- Web browser (Chrome, Firefox, Edge, etc.)


Installation:

1.	Clone the repo or download the .zip archive

   Git clone <your-repo-url>

2.	Unpack the archive, if downloaded

3.	There is no build process or packages to install – it is a static website


Setup and Execution:

1.	Open the `MyWebWebsite` directory

2.	Double-click `index.html` or open it in your browser


3.	Use the site navigation to move from one page to another
